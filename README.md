# UT2 - Actividad 12: Documentación de Código

Repositorio grupal para el desarrollo, documentación con JSDoc y revisión cruzada de archivos JavaScript.

---

## Integrantes y Distribución de Tareas

Cada integrante se ha encargado de revisar, documentar y comentar el archivo `.js` de una compañera:

| Integrante | Rama | Archivo a Documentar | Descripción del Ejercicio |
| :--- | :--- | :--- | :--- |
| **Andrea** | `andrea` | `parImpar.js` | Comprobación de números pares e impares |
| **Ainhoa** | `ainhoa` | `calcularMedia.js` | Cálculo de la media de notas |
| **Carla** | `carla` | `areaRectangulo.js` | Cálculo del área de un rectángulo |

---

## Fase 2: Metodología de Documentación

En esta fase se ha llevado a cabo una **revisión cruzada** de código siguiendo estos pasos:

1. **JSDoc Básico:** Se añadió la documentación con el estándar JSDoc (`@param`, `@returns`) en el archivo asignado a cada integrante.
2. **Comentarios de Revisión:** Cada revisora añadió comentarios explicativos en el código (`// Comentario del compañer@:`).
3. **Aclaración del Autor/a:** El/la autor/a original del código añadió sus propias precisiones debajo (`// Comentario del autor/a:`), respetando los comentarios anteriores.

---

## Estructura del Repositorio

* **`main`**: Rama principal con la versión final unificada y comentada.
* **`andrea` / `ainhoa` / `carla`**: Ramas individuales para subir los avances y revisiones antes de realizar el *Pull Request*.
